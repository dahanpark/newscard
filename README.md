# 아빠 어디가~

공개 인스타그램 여행 게시물의 확인 가능한 반응 수치를 기준으로 크기 위계를 만든 가족여행 모자이크입니다.

페이지를 열 때마다 브라우저가 캐시를 우회해 저장소의 최신 `trips.json`을 확인합니다. 데이터 구조와 반응점수 검사를 통과한 경우에만 화면의 카드·조사방법·확인시각을 교체하며, 네트워크 오류나 손상된 데이터가 있으면 배포 시점의 검증된 정적 카드 30개를 유지합니다. 이는 저장소에 게시된 최신 자료를 즉시 반영하는 기능이며, 방문자의 브라우저가 인스타그램을 직접 수집하는 기능은 아닙니다.

매주 갱신은 한국관광공사 같은 공식 관광 계정뿐 아니라 개인 여행·육아 인플루언서의 공개 게시물도 함께 조사합니다. 다음 콘텐츠 갱신부터 전국 후보 90개 이상과 서울·서울근교 후보 90개 이상에서 공개 반응 수치와 가족 나들이 적합성을 확인해 `전국 30선`과 `서울·근교 30선`을 별도로 만듭니다. 인스타그램 전체 순위를 뜻하지 않습니다.

## 기준

- 표본: 한국관광공사와 개인 여행·지역생활 공개 계정 5곳에서 확인한 가족 나들이 관련 게시물 58건 중 비교 가능한 30건
- 확인: 2026-10-01 KST
- 정렬: 공개 반응점수(`좋아요 + 댓글 × 5`) 내림차순
- 주의: 인스타그램 전체 인기 순위가 아니며, 운영시간·요금·행사일정은 방문 전 공식 채널 재확인이 필요합니다.

현재 화면의 `서울·근교` 필터는 기존 30선 중 서울·인천·경기 게시물을 먼저 모아 보여줍니다. 다음 콘텐츠 갱신부터는 전국 30개와 별도로 서울 12개 이상·인천/경기 12개 이상을 포함한 서울·근교 30개를 제공합니다.

## 로컬 확인

다음 명령으로 정적 미리보기 서버를 열고 `http://127.0.0.1:8765`에서 확인합니다. 데이터 검증도 함께 실행할 수 있습니다.

```sh
node scripts/serve.mjs
node scripts/build.mjs
node scripts/validate.mjs
```

`trips.json`을 수정한 뒤에는 반드시 `node scripts/build.mjs`를 실행해 카드 HTML을 `index.html`에 정적으로 기록합니다. 따라서 JavaScript가 꺼져도 모자이크 콘텐츠와 원문 링크가 남습니다.

`file://`로 `index.html`을 직접 열면 브라우저 보안 정책상 JSON 요청이 제한될 수 있습니다. `node scripts/serve.mjs`로 로컬 서버를 실행하면 실제 배포와 같은 자동 최신 자료 확인 동작을 검증할 수 있습니다.

`main` 브랜치에 push하면 검증 통과 후 GitHub Pages 배포 워크플로가 실행됩니다. 저장소의 Pages 소스는 **GitHub Actions**로 설정해야 합니다.
