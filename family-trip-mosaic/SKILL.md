# Family Trip Mosaic

제목은 **아빠 어디가~**로 유지한다. 가족이 함께 갈 만한 국내 여행·축제·체험 게시물을 공개 인스타그램에서 찾아 모자이크형 웹페이지로 편집한다.

## 조사 원칙

- 로그인이나 우회 수집 없이 공개 프로필·게시물에서 직접 확인되는 정보만 사용한다.
- 인스타그램 전체 순위를 주장하지 않는다. 조사한 계정, 기간, 표본 수와 확인 시각을 화면에 공개한다.
- 좋아요·댓글 등 같은 조건으로 비교 가능한 공개 수치로 순위를 정한다. 수치가 숨겨진 게시물은 별도 그룹으로 둔다.
- 장소 운영시간·가격·행사기간은 게시물 작성 시점 정보일 수 있음을 알리고, 방문 전 공식 채널 재확인을 안내한다.
- 어린이 동반 난이도, 예약 필요, 행사 종료 등 안전과 일정에 영향을 주는 표식을 숨기지 않는다.
- 게시물 이미지는 인스타그램의 공개 미리보기 주소를 사용하고 원문으로 연결한다. 이미지가 실패해도 제목과 정보가 보이도록 디자인한다.

## 7색 검토

화이트는 후보와 공개 반응 수치를 기록한다. 블랙은 가족이 2초 안에 이해할 짧은 제목을 쓴다. 레드는 수치·날짜·장소와 과장 표현을 대조한다. 블루는 가족여행 가치가 분명한지 변론한다. 실버는 부모 독자의 정보 부족과 불편을 찾는다. 퍼플은 모자이크 크기 위계와 반응형·접근성을 다듬는다. 퍼플2는 전체 리듬과 완성도를 최종 평가한다.

각 역할은 10점 만점 9.5점 이상이어야 한다. 한 역할이라도 미달하면 수정 후 전체를 다시 검토한다. 공개 근거가 부족하면 점수를 올리지 말고 게시를 보류한다.

## 디자인

- 데스크톱은 12열 모자이크를 기본으로 한다. 반응 1–2위는 가장 크게, 3–5위는 중형, 나머지는 소형으로 배치한다.
- 태블릿과 모바일에서는 카드가 읽기 좋은 2열 또는 1열로 재배치되어야 한다.
- 이미지 위에 짧은 제목, 지역, 유형, 공개 반응 수치만 상시 노출한다.
- 호버와 키보드 포커스에서 요약·주의사항을 보여주고 클릭하면 해당 인스타그램 원문을 새 탭으로 연다.
- 색과 크기만으로 순위를 전달하지 말고 순위 숫자와 좋아요 수를 함께 표시한다.

## 검증과 게시

`node scripts/validate.mjs`로 JSON 구조, 순위, 중복, 링크, 공개 수치, 검토 점수를 검사한다. 데스크톱·태블릿·모바일에서 카드 크기, 포커스, 이미지 실패 상태를 확인한다. GitHub 반영 전 비밀키와 추적 URL이 없는지 diff를 검토한다.
