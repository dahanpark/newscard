# 서울·서울근교 30선

서울·근교 목록을 조사하거나 데이터 구조·검증을 수정할 때 읽는다.

## 범위

- `seoul`: 서울특별시 25개 자치구 안의 장소와 행사.
- `near-seoul`: 인천광역시 또는 경기도 안의 장소와 행사.
- 행정구역이 불분명한 복수 장소 모음은 각 장소를 분리할 수 있을 때만 포함한다.
- 강원·충청 등은 이동시간이 짧더라도 `near-seoul`로 넣지 않는다. 일관된 행정 경계를 우선한다.

## 두 목록

`trips.json`은 다음 두 배열을 목표 구조로 사용한다.

```json
{
  "nationalItems": [],
  "seoulMetroItems": []
}
```

- 두 배열은 각각 정확히 30개이며 URL이 서로 중복되지 않아야 한다.
- `nationalItems`는 모두 `scope: "national"`이어야 한다.
- `seoulMetroItems`는 `scope: "seoul"` 12개 이상과 `scope: "near-seoul"` 12개 이상을 포함한다.
- 각 배열 안에서 `rank`는 1부터 30까지 연속이고 `engagementScore` 내림차순을 기본으로 한다. 지역 할당 때문에 순서가 바뀌면 화면의 조사 방법에 이를 밝힌다.

## 화면과 검증

- 최상위 범위 버튼은 `전국 30`과 `서울·근교 30`이다. 범위를 바꾸면 해당 배열만 보인다.
- `체험·자연·문화·휴식`은 두 번째 필터이며 현재 범위 안에서만 적용한다.
- 초기 화면은 `서울·근교 30`으로 한다.
- 정적 HTML에 60개 카드가 모두 들어 있어야 하며 JavaScript는 표시 전환만 담당한다.
- 검증기는 전체 60개, 배열별 30개, URL 중복 없음, 서울·근교 12+12 할당, 계정 수·계정별 상한, 이미지 존재를 확인한다.
